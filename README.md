# ♿ RollEase: Aplikasi Navigasi Aksesibilitas Berbasis Visual-Preview

[cite_start]RollEase merupakan aplikasi mobile berbasis sistem navigasi aksesibel yang dirancang untuk membantu pengguna kursi roda dalam menentukan rute perjalanan yang aman, nyaman, dan ramah disabilitas[cite: 28, 72]. Proyek ini dikembangkan sebagai bagian dari Program Kreativitas Mahasiswa - Karsa Cipta (PKM-KC).

## 📝 Overview Aplikasi

[cite_start]RollEase hadir untuk menjawab tantangan aksesibilitas infrastruktur publik bagi penyandang disabilitas fisik, khususnya pengguna kursi roda[cite: 17, 18, 73]. [cite_start]Meskipun sistem navigasi digital konvensional sudah umum digunakan, sebagian besar belum menyediakan informasi mikro-aksesibilitas yang krusial seperti keberadaan ramp, lift, kemiringan jalan, atau hambatan fisik lainnya[cite: 23, 24, 58].

[cite_start]Sistem ini menerapkan konsep **Visual-Preview Path Mapping**, yang memungkinkan pengguna untuk melihat gambaran visual kondisi jalur pada titik-titik kritis sebelum melakukan perjalanan[cite: 28, 29]. Dengan menggabungkan algoritma navigasi cerdas dan kontribusi data berbasis komunitas (*crowdsourcing*), RollEase bertujuan untuk:
* [cite_start]**Meningkatkan Kemandirian:** Memungkinkan pengguna melakukan navigasi mandiri tanpa ketergantungan penuh pada bantuan orang lain[cite: 40, 77].
* [cite_start]**Mengurangi Risiko:** Membantu pengguna mengenali rintangan atau jalur yang tidak aksesibel lebih awal[cite: 41, 77].
* [cite_start]**Membangun Ekosistem Inklusif:** Mendorong kesadaran masyarakat melalui peran *Mapper* dalam memetakan fasilitas publik yang ramah disabilitas[cite: 43, 67].

## ✨ Fitur Utama

RollEase memiliki tiga modul utama yang saling terintegrasi:

* [cite_start]**Navigasi Accessible:** Algoritma penentuan rute yang memprioritaskan jalur bebas tangga dan mempertimbangkan keamanan jalur bagi kursi roda[cite: 74].
* [cite_start]**Visual Path-Mapping (Visual-Preview):** Galeri foto kondisi jalur pada titik-titik kritis agar pengguna dapat melakukan verifikasi mandiri sebelum perjalanan[cite: 26, 75].
* [cite_start]**Reporting System (Crowdsourcing):** Fitur bagi pengguna untuk melaporkan hambatan jalan atau kendala aksesibilitas secara real-time[cite: 76].

## 🛠️ Teknologi yang Digunakan

Aplikasi ini dibangun dengan mengintegrasikan sistem pemetaan komunitas dan pengolahan data spasial:

* **Frontend:** Android Mobile App (Desain UI/UX dikembangkan menggunakan Figma).
* [cite_start]**Pemetaan:** OpenStreetMap (OSM) - Database peta gratis yang dapat diakses dan dikembangkan secara terbuka[cite: 94, 101].
* [cite_start]**Backend & Database:** PostGIS - Database management system untuk mengolah data spasial seperti titik, garis, dan poligon rute[cite: 96, 97].
